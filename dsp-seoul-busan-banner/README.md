# Discover Seoul Pass banner

Copy versions for the Discover Seoul Pass partner image (minimum 800 x 550, landscape). Built at 1600 x 1100.

Rebuild: `~/.venvs/office312/bin/python build.py` (needs Pillow and numpy; it re-renders any image that comes out with a black block)

Background: the N Seoul Tower and Busan Blueline panels are cut from the Door2Door hero image (D2D_HeroImage.png, 1420 x 1242) with the headline painted out, then enlarged. The designer should replace them with the original photos for the final set.
